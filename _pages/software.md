## Softwares


### 2. NonparaTransport
An R package for efficient multivariate distributional data analysis. [[Package and documentation](https://github.com/IrinaStatsLab/NonparaTransport)]

**Authors:** **Park, J.**, Gaynanova, I.



Related papers:

- [Fréchet regression of multivariate distributions with nonparanormal transport](https://arxiv.org/abs/2603.07014)
- [Fast distance computation between multivariate distributions via nonparanormal Transport](https://arxiv.org/abs/2603.00322)

### 1. OptiThresholdR

An R package for determining optimal thresholds for wearable device measurements. [[Package and documentation](https://github.com/IrinaStatsLab/OptiThresholds/blob/main/optithresholdr/README.md)]

**Authors:** **Park, J.**, Kok, N., Sousa, F., Gaynanova, I.



Related paper:

- [Beyond fixed thresholds: optimizing summaries of wearable device data via piecewise linearization of quantile functions](https://doi.org/10.1002/sim.70646)
